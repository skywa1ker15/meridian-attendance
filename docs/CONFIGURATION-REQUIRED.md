# Configuration required from Meridian Group

This is the one checklist of every value only Meridian can supply. The system cannot
go live until the items marked **Required** are done. Placeholders in the repository
look like `<<...>>` (env templates), `<domain>` (docs) or are labelled
"placeholder" (seed data, logo).

## G. Activation order

1. A1–A6 → deploy staging, then production (`deploy/README.md`).
2. F1 → create the first admin; D1–D8, E1–E15 → configure.
3. B1, C1 (+ B2/B3) → signed release build with the production URL.
4. F4–F6 → privacy notice issued.
5. F7 → pilot (`PILOT-TEST-PLAN.md`), then tune D3/D4.
6. F3, B8 → register employees and distribute.
7. A8, A10 → backups off-site and alerts verified.
